# Demo self-contained Python script to render a Quarto document using nbstata Jupyter kernel

To run this example you need

* [uv installed](https://docs.astral.sh/uv/getting-started/installation/)
* [Quarto installed](https://quarto.org/docs/get-started/)
* Stata installed (either from [Software Center/Company Portal](https://uob.sharepoint.com/sites/itservices/SitePages/stata.aspx) or [OnTheHub](https://bristol-ac.onthehub.com/))

Then to render the Quarto document run from zsh/bash/Git Bash shell

```sh
./render
```

Additional information on self-contained (i.e., scripts with inline metadata) executable Python scripts

* <https://pydevtools.com/handbook/how-to/how-to-write-a-self-contained-script/>
